THIRD-PARTY API SERVICES USED IN ACENT MESSENGER FLUTTER APPLICATION
=====================================================================

1. Firebase Cloud Messaging (FCM)
   Firebase Cloud Messaging service is used for push notifications to deliver real-time alerts, messages, and incoming call notifications to users across Android, iOS, and web platforms.

2. Pusher
   Pusher Channels service provides real-time WebSocket connections for instant messaging, live chat updates, typing indicators, and presence tracking between users in the application.

3. Agora RTC Engine
   Agora Real-Time Communication platform enables voice and video calling functionality, providing low-latency audio and video streaming for peer-to-peer and group calls within the app.

4. Soniox Real-Time Speech Recognition
   Soniox real-time transcription service provides live speech-to-text conversion with built-in translation capabilities, speaker diarization, and WebSocket-based streaming for on-screen translator functionality.

5. Azure Translator API
   Microsoft Azure Translator service handles text translation between multiple languages, enabling users to communicate across different language barriers through the backend API.

6. AWS S3 (Amazon Simple Storage Service)
   Amazon S3 cloud storage service is used for storing and retrieving user-generated content such as profile pictures, media files, and other attachments uploaded through the application.
6. QuickNode(Currently Commented)
   QuickNode is used for connecting to the blockchain server and interacting with the transaction.
