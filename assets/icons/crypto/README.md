# Cryptocurrency Icons

This folder contains the cryptocurrency icons used in the wallet screen.

## Required files:
- bitcoin.png (Bitcoin logo)
- ethereum.png (Ethereum logo) 
- bnb.png (Binance Coin logo)

## Recommended specifications:
- Format: PNG with transparency
- Size: 64x64 pixels or higher (square aspect ratio)
- Background: Transparent
- Quality: High resolution for crisp display

## Where to get official icons:
- Bitcoin: https://bitcoin.org/en/bitcoin-paper
- Ethereum: https://ethereum.org/en/assets/
- Binance: https://www.binance.com/en/official-brand-assets

## Usage:
These icons are displayed in the wallet currency tiles at 24x24 pixels.
