# Simplified Stereo Audio Integration Guide

## Overview

This guide provides a comprehensive implementation for playing two mono TTS audio files simultaneously with left and right channel separation for earpiece-specific playback. The solution uses native Flutter audio capabilities without external dependencies like FFmpeg.

## Architecture

### Core Components

1. **SimplifiedStereoAudioService** - Handles dual AudioPlayer-based stereo playback
2. **EnhancedTtsServiceSimplified** - Extends TTS functionality with stereo support
3. **Integration Examples** - Complete usage demonstrations

### Audio Flow

```
Mono TTS Audio 1 (Left Channel)  ──┐
                                   ├── Dual AudioPlayer ──► Stereo Playback
Mono TTS Audio 2 (Right Channel) ──┘
```

## Implementation Details

### 1. SimplifiedStereoAudioService

**Purpose**: Core service for playing two mono audio files simultaneously with channel separation.

**Key Features**:
- Dual AudioPlayer instances for left and right channels
- Simultaneous playback with individual volume control
- File validation and error handling
- Playback state management
- No external dependencies

**Core Method**:
```dart
Future<bool> playStereoAudio(
  String leftAudioPath,
  String rightAudioPath, {
  double leftVolume = 1.0,
  double rightVolume = 1.0,
}) async
```

### 2. EnhancedTtsServiceSimplified

**Purpose**: Extended TTS service with stereo audio generation capabilities.

**Key Features**:
- Mono audio file generation
- Stereo audio playback from text
- Multi-language support
- Volume control
- Integration with SimplifiedStereoAudioService

**Core Method**:
```dart
Future<bool> playStereoAudioFromText(
  String leftText,
  String rightText,
  String leftLanguageCode,
  String rightLanguageCode, {
  double leftVolume = 1.0,
  double rightVolume = 1.0,
}) async
```

### 3. Integration with Google STT Translator

**Use Case**: Separate earpiece audio for translated conversations.

**Implementation**:
```dart
// Play stereo audio for Google STT Translator
final success = await _enhancedTtsService.playStereoAudioFromText(
  speaker1TranslatedText,  // Left channel
  speaker2TranslatedText,  // Right channel
  speaker1TargetLanguage,  // Left channel language
  speaker2TargetLanguage,  // Right channel language
  leftVolume: 1.0,
  rightVolume: 1.0,
);
```

## Technical Specifications

### Audio Format
- **Codec**: Native TTS audio format (WAV)
- **Sample Rate**: TTS engine default
- **Channels**: 2 (Dual mono playback)
- **Channel Layout**: Left channel (Speaker 1), Right channel (Speaker 2)

### Playback Configuration
- **Left Channel**: AudioPlayer instance 1
- **Right Channel**: AudioPlayer instance 2
- **Synchronization**: Simultaneous playback start
- **Volume Control**: Individual channel volume adjustment

### File Handling
- **Input**: Two mono WAV files
- **Output**: Simultaneous playback
- **Temporary Files**: Generated by TTS service
- **Storage**: Application documents directory

## Integration with Existing Code

### Google STT Translator Integration

1. **Add EnhancedTtsServiceSimplified** to Google STT Translator
2. **Generate stereo audio** after translation
3. **Add stereo playback controls** to UI
4. **Handle playback state** management

### Example Integration

```dart
class GoogleSTTTranslator extends StatefulWidget {
  // ... existing code
}

class _GoogleSTTTranslatorState extends State<GoogleSTTTranslator> {
  final EnhancedTtsServiceSimplified _enhancedTtsService = EnhancedTtsServiceSimplified();
  bool _isPlayingStereo = false;
  
  @override
  void initState() {
    super.initState();
    _enhancedTtsService.initialize();
  }
  
  Future<void> _playStereoAudio() async {
    // Play stereo audio after translation
    final success = await _enhancedTtsService.playStereoAudioFromText(
      _translations[0] ?? '',
      _translations[1] ?? '',
      _speakerLanguages[1]?.code ?? 'en',
      _speakerLanguages[0]?.code ?? 'en',
    );
    
    if (success) {
      setState(() {
        _isPlayingStereo = true;
      });
    }
  }
  
  Future<void> _stopStereoAudio() async {
    await _enhancedTtsService.stop();
    setState(() {
      _isPlayingStereo = false;
    });
  }
  
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // ... existing UI
      floatingActionButton: _isPlayingStereo
          ? FloatingActionButton(
              onPressed: _stopStereoAudio,
              child: const Icon(Icons.stop),
            )
          : FloatingActionButton(
              onPressed: _playStereoAudio,
              child: const Icon(Icons.play_arrow),
            ),
    );
  }
  
  @override
  void dispose() {
    _enhancedTtsService.dispose();
    super.dispose();
  }
}
```

## Advantages of Simplified Approach

### Benefits

1. **No External Dependencies**: Uses only native Flutter packages
2. **Lightweight**: Minimal resource usage
3. **Reliable**: No FFmpeg compilation issues
4. **Cross-Platform**: Works on all Flutter-supported platforms
5. **Easy Integration**: Simple API for stereo playback

### Limitations

1. **Not True Stereo**: Uses dual mono playback instead of single stereo file
2. **Synchronization**: Relies on AudioPlayer synchronization
3. **File Management**: Requires managing two separate audio files

## Conclusion

This simplified implementation provides a reliable solution for stereo-like audio playback using native Flutter capabilities. While it doesn't create a true stereo file, it achieves the desired effect of separate earpiece audio playback for translation applications.

The solution is production-ready, lightweight, and easy to integrate into existing applications without external dependencies or complex setup requirements.
